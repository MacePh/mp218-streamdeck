# MPD StreamDeck banner and header package

## Purpose
Create the supporting branding assets that sit alongside the icon package so MPD StreamDeck has a coherent visible identity across repo pages, docs, splash surfaces, and social/header contexts.

## Package contents

### 1. GitHub / repo header banner
- Wide horizontal composition
- Primary lockup or horizontal logo
- Dark background preferred
- Minimal but stylish synthwave / neon-tech atmosphere
- Should work as a README/repo header image

Target exports:
- 2400x800 PNG
- 1600x600 PNG

### 2. Hero / splash banner
- More expressive version
- Can include subtle cosmic / neon environment
- Use the stronger poster energy version of the branding
- Still keep the logo legible and central

Target exports:
- 1920x1080 PNG
- 2560x1440 PNG

### 3. Social/share card
- Horizontal social image
- Logo + project name clearly readable
- Strong visual identity without clutter

Target exports:
- 1200x630 PNG
- 1600x900 PNG

### 4. Lightweight docs banner
- Cleaner, lower-noise version for documentation pages
- Prioritize readability and clean composition

Target exports:
- 2000x500 PNG
- 1600x400 PNG

## Visual direction

### Keep
- primary selected logo system
- neon-tech / retro-futuristic identity
- magenta / cyan / purple accents
- tactile command-surface mood
- geometric clarity

### Avoid
- overbusy poster chaos in repo headers
- illegible wordmark
- fake hardware clutter dominating the composition
- tiny unreadable labels
- too much background detail near text/logo edges

## Recommended usage

### GitHub / docs
- use repo header banner or lightweight docs banner

### Website / splash
- use hero banner

### Social / previews
- use social/share card
