# MPD StreamDeck branding workspace

This folder is the canonical home for MPD StreamDeck branding assets inside the repo.

## Intended structure
- `raw/` — original generated images / source comps
- `icons/` — icon-only exports and app icons
- `logos/` — primary lockups, horizontal versions, monochrome marks
- `banners/` — repo headers, splash art, social cards
- `exports/` — final picked assets for immediate use
