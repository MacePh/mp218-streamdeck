# MPD StreamDeck icon package

## Selected branding direction
Use the latest refined logo system as the source of truth, with:
- **Primary logo lockup** = top main lockup from the refined branding sheet
- **Primary icon/emblem** = icon-only grid mark from the refined branding sheet
- **Secondary expressive asset** = more neon / expressive version for splash or hero use only

The icon package should optimize for clarity, repeatability, and immediate usability across repo, app, and launcher contexts.

## Package contents

### 1. App icon / launcher icon
- Square composition
- Icon-only mark
- Dark background preferred
- High contrast
- Minimal extra glow
- Readable at small sizes

Target exports:
- 1024x1024 PNG
- 512x512 PNG
- 256x256 PNG
- 128x128 PNG
- 64x64 PNG
- 32x32 PNG

### 2. Transparent icon mark
- Icon-only
- Transparent background
- Clean edges
- Minimal glow variant
- Optional neon-edged variant

Target exports:
- transparent PNG at 1024x1024
- transparent PNG at 512x512

### 3. Primary logo lockup
- Icon + wordmark
- Dark-background version
- Light-background version
- Transparent-background version if possible

Target exports:
- 2400px wide PNG
- 1600px wide PNG
- transparent PNG version

### 4. Horizontal header lockup
- Emblem left, wordmark right
- Suitable for GitHub/README/header use

Target exports:
- 2400x800 PNG
- 1600x600 PNG

### 5. Minimal monochrome mark
- Black version
- White version
- Flat, low-effect version

Target exports:
- transparent PNGs
- SVG recreation later if needed

## Visual rules

### Keep
- clean grid emblem
- retro-futuristic / neon-tech tone
- magenta / cyan / purple accent system
- strong geometric readability
- tactile control-surface feel

### Avoid
- fake hardware clutter
- busy poster backgrounds in icon exports
- unreadable glow-heavy details
- overcomplicated gradients
- random tiny labels or pseudo-UI noise

## Recommended usage

### Use icon-only mark for
- app icon
- launcher tile
- avatar
- favicon base
- desktop shortcut artwork

### Use primary logo lockup for
- repo branding
- docs header
- splash screen
- about page

### Use expressive version for
- hero art
- wallpaper
- promotional banner
- social image
